# Pass Icons Directory

This directory should contain icons for your Apple Wallet passes.

## Required Files

Apple Wallet requires the following icon files:

### Icon Files
- `icon.png` - 29×29 pixels
- `icon@2x.png` - 58×58 pixels
- `icon@3x.png` - 87×87 pixels (optional but recommended)

### Logo Files
- `logo.png` - 160×50 pixels
- `logo@2x.png` - 320×100 pixels
- `logo@3x.png` - 480×150 pixels (optional but recommended)

## Design Guidelines

1. **Icon**: Should be your app icon or a simplified membership badge
2. **Logo**: Should be the Flagship Towing logo
3. **Format**: PNG with transparency
4. **Colors**: Should work on both light and dark backgrounds
5. **Content**: Avoid text in icons, keep it simple and recognizable

## Image Requirements

- File format: PNG
- Color space: sRGB or P3
- Transparency: Supported
- Compression: Lossless PNG

## Notes

- These images will appear on the membership pass in Apple Wallet
- Use high-quality assets for the best appearance
- Test on actual devices to ensure they look good
- This directory is in `.gitignore` - make sure to back up your assets separately
